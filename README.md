# Анализ восприятия коррупции и безопасности в Гонконге

## Описание проекта
Анализ взаимосвязи между восприятием коррупции и поведением, связанным с безопасностью, на основе данных World Values Survey (Гонконг, ~2000 наблюдений).

Проект направлен на выявление факторов, влияющих на субъективное чувство безопасности и оценку роли коррупции в формировании поведенческих решений.

---

## Цель
Оценить, влияет ли восприятие коррупции на поведение граждан, связанное с безопасностью, а также выявить влияние демографических факторов.

---

## Данные
- World Values Survey (Wave 7)
- ~2000 наблюдений (Гонконг)

---

## Методы
- Binary Logistic Regression  
- Multiple Linear Regression  
- Moderation Analysis  
- Statistical Inference  

---

## Основные результаты
- Более высокая оценка уровня коррупции увеличивает вероятность защитного поведения (+10% к шансам)  
- Демографические факторы оказывают влияние на восприятие коррупции  
- Влияние доверия к полиции не является статистически значимым
